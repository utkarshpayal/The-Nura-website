## Security claims on this site

`/security` (Security & Safety), `/privacy`, `/data-protection`, `/faq` and the
safety section on Home all describe how Nura protects data. They must match
the API's [SECURITY.md](https://github.com/utkarshpayal/period-buddy-be/blob/main/docs/SECURITY.md),
the single source of truth:

- Never claim end-to-end encryption, on-device encryption of health logs,
  certifications, or where data is stored, unless `SECURITY.md` says so.
- When a protection changes in the product, update `SECURITY.md` first, then
  these pages, and bump the "Last updated" date on `/security` and
  `/data-protection`.
